Проектик - поисковик самолётов.

Реализовано:
1. Доступ к открытым ресурсам информации о самолётах в воздухе;
2. фильтр данных по месту нахождения самолётов (над выбранной страной);
3. фильтрация по высоте полёта самолёта (задаётся интересующий диапазон высот);
4. фильтрация по стране - регистрации самолёта (задаётся список стран);
5. сортировка по высоте или скорости полёта (от большего значения к меньшему);
6. для удобства реализован ввод страны на русском языке;
7. ... продолжение следует ...
